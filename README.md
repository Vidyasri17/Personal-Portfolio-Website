# Personal Portfolio Website

This is a fully responsive, animated personal portfolio website built with React, Vite, and Framer Motion. It showcases my skills, projects, and provides a way to get in touch.

## Features

- **Responsive Design**: Works flawlessly on mobile, tablet, and desktop devices.
- **Parallax Scrolling**: Includes smooth background parallax effects for depth.
- **On-Scroll Animations**: Elements gracefully reveal themselves as you scroll down using Framer Motion.
- **Accessibility**: Respects `prefers-reduced-motion` system preferences for accessible animations.
- **Modern UI/UX**: Designed with a sleek, dark-themed aesthetic and glassmorphism elements.

## Tech Stack

- React (with Vite for fast bundling)
- Vanilla CSS (with CSS Modules for scoped styling)
- Framer Motion (for on-scroll animations)
- React Scroll Parallax (for parallax effects)
- Lucide React & React Icons (for vector icons)

## Local Setup

Follow these steps to run the project locally:

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd <repository-directory>
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
